# suvisdev

**AI 영화 추천(Mova) · 반려견 산책 경로(Gildle) 통합 플랫폼**
{: .fs-6 .fw-300 }

직접 파인튜닝한 소형 LLM이 도구를 골라 답하는 영화 채팅과, 건물 그림자까지 계산하는 보행 경로 추천을 하나의 모듈러 모놀리식 백엔드에 담아 노트북 한 대로 운영하는 풀스택 프로젝트.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 영화 채팅 에이전트 | 파인튜닝한 EXAONE 3.5 2.4B가 도구 10개 중 하나를 고르고, 사실(출연진·시간표·OTT)은 코드 템플릿이 답한다 |
| AI 맞춤 추천 | EXAONE 3.5 2.4B LoRA(GGUF, 집 서버 GPU) + Gemini 자동 폴백, 취향 벡터 재정렬 |
| 봤어요 · 별점 | 채팅에서 "인셉션 봤어 4점" 한 문장으로 기록, 취향 추천·취향 요약에 반영 |
| AI 에디터 리뷰 | 뉴스 요약 기반 리뷰 자동 생성 + 감정분석 별점 + 출처 링크 |
| 박스오피스 랭킹 | KOFIC API 일별/주간/월간 집계 · 시각화 |
| 산책 경로 후보 | 서울 전역 보행 그래프 23만 간선에서 빠른·그늘·푸른·편한 길을 이유와 함께 제시 |
| 그늘 경로 | 건물 그림자를 월별 × 시간대로 미리 계산해 같은 구간도 시각에 따라 다른 길 |
| 문장으로 산책 추천 | "40분 동안 3키로 편하게" → 출발지로 돌아오는 코스 추천 |
| 웹 · 앱 | Next.js 웹과 Flutter 안드로이드 앱(길들)이 같은 API를 쓴다 |
| 인증 | Google·Kakao·Naver OAuth 2.0, httpOnly 쿠키 세션, RBAC |
