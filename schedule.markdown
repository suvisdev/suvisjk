## 위험 관리 방안

| 위험 요소 | 영향 | 대응 |
|-----------|------|------|
| GPU 서버 다운 | 추천 서비스 중단 | Gemini 자동 폴백 + 서킷 브레이커(연속 2회 실패 → 60초 우회 → 자동 복귀) |
| 노트북 전원·네트워크 | API 전체 중단(프론트만 생존) | 감수한 트레이드오프 — 클라우드 분리안은 비용·지연으로 기각(09-29) |
| 환경 변수 누락 | 빈 자격증명으로 기동 | 배포 스크립트가 `.env` → Secret 변환, 없으면 즉시 실패 |
| 외부 API 제한 | 수집 실패 | 타일 분할·미러 순환·지수 백오프·이어받기, 부분 수집 허용 |
| VRAM 경합 | 운영 추론 + 학습 동시 불가(8GB) | 학습은 Colab에서 GGUF까지 완결, 노트북 GPU는 운영 전용 |
| 소형 모델 천장 | 2.4B 판단 모델이 재학습해도 v9(77/86)를 못 넘음 | 새 기능은 프롬프트 예시로 얹고, 사실·기록은 코드 가드로 보호 |
| 하네스 밖 장면 | 실사용에서만 드러나는 버그 | 실사용 대화를 평가셋·회귀 테스트에 그대로 추가 |
